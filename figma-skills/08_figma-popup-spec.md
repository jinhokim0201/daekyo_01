### 팝업 유형 구분

#### 유형 1 — 전체 오버레이 팝업 (POP01, POP02, POP03)
- 배경 화면 전체에 팝업 UI가 표시되는 방식
- 팝업 콘텐츠가 브라우저 page content 내부에 포함
- 별도 Modal 프레임 없이 페이지 자체가 팝업 화면

```
브라우저(x=59,y=150,w=1940,h=1357)
└── 크롬(h=64)
└── 페이지콘텐츠(y=64) ← 팝업 UI 직접 배치
```

#### 유형 2 — 소형 모달 팝업 (POP05 시리즈, POP06)
- 배경 화면 위에 모달 다이얼로그가 overlay로 표시
- Modal 프레임이 스펙 프레임의 직접 자식으로 배치
- 브라우저 중앙에 위치

---

### 소형 모달 위치 계산 공식 (브라우저 중앙 정렬)

```
브라우저 중심 x = 59 + 1940/2 = 1029
브라우저 중심 y = 150 + 1357/2 ≈ 829

모달 x = 1029 - (modal_w / 2)
모달 y = 829  - (modal_h / 2)
```

#### 실제 예시
| 팝업 | w | h | x | y |
|------|---|---|---|---|
| 총학생수 | 540 | 324 | 759 | 667 |
| 신청완료 | 540 | 244 | 759 | 707 |
| 신청대기 | 540 | 164 | 759 | 747 |
| 미신청 | 540 | 204 | 759 | 727 |
| 알림톡발송이력 | 500 | 241 | 779 | 709 |

#### 코드 헬퍼
```javascript
function calcModalPosition(modalW, modalH) {
  return {
    x: Math.round(1029 - modalW / 2),
    y: Math.round(829  - modalH / 2)
  };
}
// 예: w=540, h=300 → { x: 759, y: 679 }
```

### 소형 모달 생성 패턴
```javascript
const { x: mx, y: my } = calcModalPosition(540, 300);
const modal = figma.createFrame();
specFrame.appendChild(modal); // 스펙 프레임의 직접 자식
modal.x = mx;
modal.y = my;
modal.resize(540, 300);
modal.cornerRadius = 8;
modal.fills = [{ type: 'SOLID', color: { r: 1, g: 1, b: 1 } }];
modal.effects = [{
  type: 'DROP_SHADOW',
  color: { r: 0, g: 0, b: 0, a: 0.15 },
  offset: { x: 0, y: 4 },
  radius: 16,
  spread: 0,
  visible: true,
  blendMode: 'NORMAL'
}];
modal.name = 'Modal_팝업명';
```

### ⚠️ 팝업 누락 체크리스트
새 스펙 작업 시 아래 항목 확인:

- [ ] 메인 화면에서 버튼 클릭으로 열리는 팝업 목록 파악
- [ ] 각 팝업에 대응하는 SPEC_POP 프레임 존재 여부 확인
- [ ] SPEC_POP 번호가 순서대로 부여되었는지 확인
- [ ] 팝업 유형(전체 오버레이 vs 소형 모달) 결정
- [ ] 소형 모달은 `calcModalPosition()` 으로 중앙 정렬 좌표 계산
- [ ] 팝업 스펙에도 디스크립션 패널 및 서클 추가
- [ ] 메인 스펙 DESC에 "클릭 시 SPEC_POPXX 호출" 명시

### 새 팝업 스펙 추가 시 위치 계산
기존 팝업 스펙들은 x 방향으로 ~2765+65 간격, y 방향으로 묶음 배치:
- 신규 추가 시 같은 기능 그룹의 마지막 스펙 오른쪽 또는 아래에 배치
- 간격: x += 2765 + 80 (우측 배치) 또는 y += 1645 + 80 (하단 배치)
