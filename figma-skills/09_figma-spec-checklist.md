# 스킬: figma-spec-checklist
## 스펙 작업 전후 검증 체크리스트

---

### 작업 전 확인
- [ ] 올바른 Figma 페이지로 전환했는가? (`await figma.setCurrentPageAsync(adminPage)`)
- [ ] 대상 노드 ID가 현재 페이지에 존재하는가? (`figma.getNodeById(id)` 결과 확인)
- [ ] 필요한 폰트를 모두 로드했는가? (Noto Sans KR, Inter)
- [ ] `SKIP_CH` 및 `findTexts` 헬퍼를 코드 상단에 포함했는가?

---

### 서클(Circle) 작업 확인
- [ ] 각 서클에 `setProperties({ number: 'N', color: ... })` 가 호출되었는가?
- [ ] ①② 서클은 `color: 'red'`, 나머지는 `color: 'Default'` 인가?
- [ ] 11번 이상은 내부 TEXT override 처리가 되었는가?
- [ ] 서클 번호가 모두 의도한 번호로 표시되는가? (스크린샷으로 확인)

---

### 테이블 작업 확인
- [ ] 컬럼 추가 전 테이블 총 너비를 확인했는가?
  - 현재 컬럼 총 너비 + 신규 컬럼 너비 ≤ 테이블 프레임 너비
- [ ] 헤더와 데이터 행이 동일한 x 좌표로 정렬되었는가?
- [ ] 화면 상태(발표 완료/미발표)에 맞는 데이터가 표시되는가?
  - 미발표: 데이터 행 제거 + 빈 상태 메시지

---

### 디스크립션 패널 확인
- [ ] DESC 제목이 화면 상태에 맞게 작성되었는가?
  - 읽기 전용: "조회 셀" (입력/수정 셀 아님)
  - 발표 전 버튼: "결과 발표 버튼"
  - 발표 후 메시지: "최종결과발표 안내 메시지"
- [ ] Body 내용이 실제 화면 동작과 일치하는가?
- [ ] 패널 높이가 마지막 DESC 항목을 포함하도록 resize 되었는가?

---

### 팝업 누락 확인
- [ ] 이 화면에서 열리는 팝업 목록을 파악했는가?
- [ ] 각 팝업에 대응하는 SPEC_POP 프레임이 존재하는가?
- [ ] 누락된 팝업이 있다면 SPEC_POP 추가 작업 필요
- [ ] 메인 스펙 DESC에 팝업 연결 명시가 되어 있는가?
  - 예: "• 클릭 시 회원 상세 팝업(SPEC_POP01)을 호출한다."

---

### 버튼 작업 확인
- [ ] 각 버튼이 독립된 FRAME으로 분리되어 있는가?
- [ ] active/inactive 색상이 올바르게 설정되었는가?
  - Active: `rgb(44, 95, 122)` 배경 + 흰 텍스트
  - Inactive: 흰 배경 + `rgb(44, 95, 122)` 텍스트

---

### 스펙 클론 후 확인
- [ ] 클론된 화면의 상태가 원본과 다르게 수정되었는가?
  - 버튼 active/inactive 상태
  - 테이블 데이터 (발표 전/후)
  - DESC 내용 (화면 상태 반영)
- [ ] 클론 후 스크린샷을 통해 최종 결과를 검증했는가?
